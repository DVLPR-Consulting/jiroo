# Synchronisation Linear — mode dégradé et état de réconciliation

Ce dossier sert quand Linear est indisponible ou que ses capacités sont limitées.
Il est tenu **par Claude Code**, qui centralise le pilotage Linear (voir « Rôles
des agents » dans [project-governance.md](project-governance.md)). Codex ne
l'écrit pas : en revue, il signale ses constats dans son rapport.

## Procédure (Claude)

1. Signaler la limite constatée au propriétaire.
2. Ajouter ci-dessous une entrée **NON SYNCHRONISÉ** : date, cible Linear prévue
   (projet, ticket ou document), source, état, contenu utile complet ou chemin
   du plan complet, prochaine action. Ne pas créer de seconde version d'un plan
   déjà complet ailleurs : le recenser.
3. Continuer les travaux autorisés indépendants, sans prendre de décision qui
   exige une validation inaccessible.
4. Au retour de l'accès : vérifier identité et droits, relire l'état distant,
   chercher les doublons, réconcilier, écrire, **relire après écriture**, puis
   marquer l'entrée « réconciliée le <date> » avec le lien Linear. Ne jamais
   écraser des ajouts distants avec une copie locale obsolète ; ne rien supprimer
   ni archiver sans accord.
